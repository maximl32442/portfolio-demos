# Демо-проекты для портфолио

Живой сайт: https://maximl32442.github.io/portfolio-demos/

Шесть демонстрационных сайтов на HTML, CSS и чистом JavaScript. Все компании, цены и отзывы вымышлены, это не заказы клиентов.

| № | Проект | Что показывает |
|---|---|---|
| 1 | [Лендинг кофеобжарки «Зерно»](landing/) | Одностраничник с тарифами, FAQ и формой заявки |
| 2 | [Визитка клиники «Ось»](vizitka/) | Пять страниц: услуги, работы, о нас, контакты |
| 3 | [Вёрстка по макету «Горсть»](figma-to-html/compare.html) | Сравнение макета и вёрстки, режим наложения |
| 4 | [Адаптация автосервиса «Гараж 54»](adaptive/) | Версия до и после мобильной адаптации |
| 5 | [Калькулятор и квиз «Ровно»](calculator/) | Расчёт стоимости ремонта и квиз с ветвлением |
| 6 | [HTML-письмо «Полка»](email/) | Табличная email-вёрстка 600 px с адаптивом |

Формы работают только в браузере и никуда не отправляют данные. Сайт публикуется через GitHub Pages workflow из `.github/workflows/pages.yml`.
